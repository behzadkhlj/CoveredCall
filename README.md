# Covered Call Strategy — TSE (v7)

Pipeline برای «مدیریت سبد سرمایه‌گذاری از طریق اختیار خرید پوشش‌داده‌شده» روی
بورس اوراق بهادار تهران، به همراه یک دموی آموزشیِ «تشخیص تقلب علمی» (Feature
Leakage) که کاملاً از مسیر اصلی جدا است.

## اجرا

**در Google Colab** (توصیه‌شده): فایل `covered_call_strategy.py` را باز کنید،
Drive را مانت کنید و فایل‌های CSV سهم‌ها را در
`My Drive/Covered Call Project/` قرار دهید، سپس کل فایل را اجرا کنید.

**محلی / خارج از Colab**:
```bash
pip install pandas numpy scikit-learn lightgbm xgboost optuna shap scipy matplotlib PyWavelets
python3 covered_call_strategy.py
```
فایل‌های CSV نمونه (Fameli, Fulad, IranKhodro, Khgostar, VebMellat) در پوشهٔ
`data/` قرار دارند. برای اضافه‌کردن سهم دیگر (مثل Shapna) کافی است
`data/Shapna.csv` را با همان فرمت TSETMC اضافه کنید — کد به‌صورت خودکار
شناسایی‌اش می‌کند.

## تغییرات نسخهٔ v7 نسبت به نسخهٔ قبلی

شرح کامل هر تغییر در بالای خودِ فایل `covered_call_strategy.py` (بخش
CHANGELOG) آمده؛ خلاصه:

1. **رفع باگ گیتِ بلک-شولز در بک‌تست** — نوسانِ روزانه از یک دیکشنری اشتباه
   خوانده می‌شد و همیشه `None` برمی‌گشت، یعنی گیتِ «فقط وقتی پرمیوم بازار
   منصفانه است بفروش» عملاً هرگز فعال نمی‌شد. اکنون نوسانِ واقعیِ هر روز به
   بک‌تست داده می‌شود.
2. **رفع نشتِ target در مرز Train/Val/Test** — چون target هر روز ۵ روز به
   جلو نگاه می‌کند، بدون Purge Gap چند ردیفِ آخرِ هر بخش به بخش بعدی «دید»
   داشتند. یک Purged Time-Series Split مشترک این را در سراسر HONEST و FRAUD
   حل کرده.
3. **تعدیل وقایع شرکتی (Corporate Actions)** — داده‌های خام TSETMC چند جهش
   قیمتیِ افراطی (تا -95%/+109%) دارند که مربوط به افزایش سرمایه/تجدید
   ارزیابی‌اند، نه نوسان بازار. این‌ها اکنون با روش Back-Adjustment (مشابه
   تعدیل تقسیم سهام) تعدیل می‌شوند تا target و volatility را گمراه نکنند.
4. **کشفِ پویای نمادها** — اگر فایل یک سهم موجود نباشد (مثلاً Shapna)، کد
   کرش نمی‌کند؛ با بقیه ادامه می‌دهد و هشدار می‌دهد.
5. تکرارپذیریِ بهتر (seed سراسری) و اجرای خارج از Colab بدون کرش.

هیچ‌کدام از این تغییرات فرضیات مالیِ استراتژی (نرخ بدون ریسک، پرمیوم بازار،
Strike، تعداد/نوع مدل‌ها) را تغییر نداده — فقط باگ و نشتِ داده رفع شده.

## اعتبارسنجی

نسخهٔ فعلی با یک Smoke Test کامل (تعداد trial کاهش‌یافته) روی همین ۵ فایل CSV
واقعیِ موجود در `data/` تا انتهای CELL 13.8 بدون خطا اجرا شده؛ دموی نشتِ
فیچر (CELL 5.5) دقیقاً رفتار موردانتظار را نشان داد (AUC نسخهٔ فراد همواره
بالاتر از نسخهٔ صادقانه). برای نتیجهٔ نهاییِ قابل‌استناد باید کل فایل با
تعداد trial اصلی (60/40/30) اجرا شود.
